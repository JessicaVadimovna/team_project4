# MOEX Portal

Профессиональный портал для мониторинга данных Московской биржи (MOEX). Этот проект предоставляет визуализацию биржевой информации, котировок, новостей и аналитических инструментов в современном и удобном интерфейсе.

## Особенности

- **Котировки в реальном времени**: Бегущая строка с актуальными ценами криптоактивов и индексов.
- **Интерактивные виджеты**: Графики и таблицы с наиболее активно растущими и падающими активами дня.
- **Интеграция с Картой**: Удобное отображение местоположения офисов через Яндекс.Карты.
- **Сводка Новостей**: Последние новости финансового рынка.
- **Прогноз Погоды**: Интегрированный погодный виджет для удобства пользователей.

## Стек технологий

- **HTML5/CSS3**: Семантическая верстка и современный дизайн.
- **JavaScript (ES6+)**: Динамическая подгрузка данных и интерактивность.
- **Bootstrap 5**: Основа для адаптивной сетки.
- **Swiper.js**: Для плавного переключения баннеров.
- **API Интеграции**: OpenWeather API, Cryptorank API, Yandex Maps API.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/moex-portal.git
   ```
2. Откройте `index.html` в вашем браузере.
3. Рекомендуется использовать расширение `Live Server` для VS Code для корректной работы всех функций.
